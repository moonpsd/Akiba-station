🎌 Akiba Station

Um site de animes com uma interface retrô inspirada na estética da antiga web, combinando nostalgia, cultura japonesa e uma experiência moderna de navegação.

Sobre o projeto:
O Akiba Station foi desenvolvido com o objetivo de criar uma plataforma para explorar animes, utilizando uma identidade visual retrô e uma interface intuitiva.
